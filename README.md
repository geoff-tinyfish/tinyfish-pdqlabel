# PDQ Delivery Label Maker

A local 4 x 6 black-and-white delivery label generator for Tiny Fish Printing and PDQ local courier deliveries.

## Features

- 4 x 6 Zebra-friendly label preview and print output
- Saved sender address dropdown with blind-ship address support
- Optional second destination address line
- One contents field per box in the delivery
- Automatic text sizing for destination and contents blocks
- Browser-local saved sender addresses

## Use

Open `index.html` in a browser, or serve the folder locally and visit the local URL. Use **Print / Save PDF** to print or save the 4 x 6 labels.
